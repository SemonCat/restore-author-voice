# Restore author voice

## Workflow

1. **Define the job.** Set audience, genre, venue, language, strength, and mode: diagnose, cleanup, rewrite, or draft. Finish when output, reader task, and editing boundary are clear.

2. **Lock evidence.** Preserve names, numbers, dates, links, quotations, requirements, terms, chronology, positions, and decisive contrasts. Label fact, inference, opinion, and quotation. Finish when each claim has a source and each protected item a disposition.

3. **Anchor voice.** Select 3–7 traceable anchors from the draft, instructions, or attributable samples. Use venue samples for register and format, never facts. Finish when anchors or an explicit genre default guide the edit.

4. **Diagnose first.** Read [the diagnostic lens](references/diagnostic-lens.md). Add [structure](references/structure-and-discourse.md) for narrative or long form, [venue guides](references/venue-guides.md) for professional prose, and [AI patterns](references/ai-patterns.md) for de-AI work. If evidence is missing, do not rewrite; finish the diagnosis with 1–3 explicit questions. Finish when each change fixes a located problem at a named layer.

5. **Revise deepest-first.** Fix architecture or venue fit, then flow and wording. Use the [English](references/en.md) or [Traditional Chinese](references/zh-tw.md) guide. Finish when structure serves the reader without meaning drift.

6. **Verify.** Compare with the source, run the author-swap test, and use [evaluation](references/evaluation.md) for high-risk work. Finish when protected content survives, additions are sourced, and author-specific passages fail a plausible author swap.

## Guardrails

- Optimize for truthful, effective prose, not detector scores.
- Invent no experience, quotation, number, emotion, relationship, reference, or opinion.
- Treat pattern lists as signals; preserve necessary neutrality and conventional containers.
- Build profiles only from attributable samples using the [template](templates/author-profile.md); infer no sensitive traits.
