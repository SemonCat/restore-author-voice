# Restore author voice

## Workflow

1. **Define the job.** Set audience, genre, venue, language, strength, and mode. Finish when the output, reader task, and editing boundary are clear.

2. **Lock evidence.** Preserve names, numbers, dates, links, quotations, requirements, chronology, positions, and contrasts. Distinguish fact, inference, opinion, and quotation. Finish when each claim has a source and each protected item a disposition.

3. **Anchor voice.** Choose 3–7 traceable anchors from supplied or attributable text. Use venue samples only for register and format. Finish when anchors or an explicit genre default guide the edit.

4. **Diagnose.** Read [the diagnostic lens](references/diagnostic-lens.md). Add [structure](references/structure-and-discourse.md) for narrative or long form, [venue guides](references/venue-guides.md) for professional prose, and [AI patterns](references/ai-patterns.md) for de-AI work. Ask 1–3 questions only when missing evidence changes the result. Finish when each change fixes a located problem at a named layer.

5. **Revise deepest-first.** Fix architecture or venue fit before flow and wording. Use the [English](references/en.md) or [Traditional Chinese](references/zh-tw.md) guide. Finish when structure serves the reader without meaning drift.

6. **Verify and deliver.** Compare with source, run the author-swap test, and use [evaluation](references/evaluation.md) for high-risk work. Return ready-to-use copy by default; add diagnosis or editing notes only when requested. Finish when protected content survives, additions are sourced, and author-specific passages fail a plausible author swap.

## Guardrails

- Optimize for truthful, effective prose, not detector scores.
- Invent no experience, quotation, number, emotion, relationship, reference, or opinion.
- Treat pattern lists as signals; preserve necessary neutrality and conventional containers.
- Build profiles only from attributable samples using the [template](templates/author-profile.md); infer no sensitive traits.
